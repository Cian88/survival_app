Aide et contact

Une question, un problème, une suggestion : contact@hold-out.app.

Compte

Puis-je créer mon compte sans connexion Internet ?

Oui, avec une adresse e-mail et un mot de passe. L'application est utilisable immédiatement ; le compte est enregistré en ligne automatiquement dès que le réseau revient, et l'e-mail de confirmation part à ce moment-là. Google et Apple, eux, demandent une connexion.

Puis-je me connecter hors ligne ?

Oui, sur un appareil où vous avez déjà utilisé votre compte : avec votre mot de passe, ou votre phrase de chiffrement si vous utilisez Google ou Apple. Sinon, vous restez connecté : l'application s'ouvre directement, avec ou sans réseau.

À quoi sert le code de secours ?

Vos données sont chiffrées sur votre appareil avec une clé que personne d'autre que vous ne connaît. Le code de secours, affiché une seule fois à la création du compte, permet de les retrouver si vous oubliez votre mot de passe (ou votre phrase de chiffrement). Notez-le ou imprimez-le et rangez-le hors de votre téléphone, avec vos papiers importants. Vous pouvez en générer un nouveau dans Mon profil → Mon compte.

J'ai oublié mon mot de passe

Sur l'écran de connexion, choisissez « Mot de passe oublié ? » : vous recevez un lien pour en choisir un nouveau. Dans l'application, votre code de secours vous est ensuite demandé une fois pour déverrouiller vos données. Sans ce code, vous pouvez repartir d'une sauvegarde neuve à partir des données présentes sur votre appareil.

Qu'est-ce que la phrase de chiffrement (Google, Apple) ?

Avec Google ou Apple, vous n'avez pas de mot de passe Holdout. La phrase de chiffrement le remplace pour protéger vos données et vous permet de vous reconnecter sans réseau. Elle n'est jamais transmise.

Mes données sont-elles synchronisées entre mes appareils ?

Oui : profil, inventaire, sacs, plan, contacts et points, dès que le réseau le permet. Les cartes et points téléchargés restent propres à chaque appareil : téléchargez-les sur chacun.

Supprimer votre compte

Dans l'application : Mon profil → Mon compte → « Supprimer mon compte », puis tapez SUPPRIMER. Le compte, la sauvegarde chiffrée, les sessions et les licences rattachées sont effacés immédiatement du serveur ; les données restent sur votre appareil jusqu'à ce que vous les effaciez.

Vous n'avez plus accès à l'application ? Écrivez à contact@hold-out.app depuis l'adresse de votre compte : la suppression est faite sous 30 jours au plus et vous est confirmée.

Application et cartes

Comment installer l'application sur mon téléphone ?

Ouvrez hold-out.app/app dans le navigateur, puis « Ajouter à l'écran d'accueil » (Safari : bouton Partager ; Chrome : menu ⋮). L'application fonctionne ensuite sans connexion.

Comment avoir la carte sans réseau ?

Avant d'en avoir besoin : Carte → Options → « Cartes hors ligne », choisissez la zone (autour du domicile, de votre position, ou la zone affichée) et téléchargez. Le pack contient tout le détail, jusqu'aux sentiers et aux courbes de niveau.

Comment récupérer mes données ?

Notice → « Exporter mes données » : un fichier JSON contenant tout ce que vous avez saisi. Gardez-en une copie sur une clé USB.
